03 · VARIABLES
var, let and const
var

Function scope

Visible in the whole function. Outside any function it is added to window.

let

Block scope

Visible only inside the { } block where it is declared.

const

Constant

Cannot be reassigned after it is declared.

const discount = 0.20;discount = 0.50;
Uncaught TypeError: Assignment to constant variable.
const course = {semester: "fall"}course.semester = "spring" ✓
{ semester: 'spring' }
