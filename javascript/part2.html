03 · IN JAVASCRIPT
Way 2: addEventListener
let button = document.getElementsByTagName("button")[0];button.addEventListener("click", handleClick); function handleClick() { alert("The button was clicked");}
handleClick

You hand over the function. The browser calls it on every click.

handleClick()

Calls it right now, once, and passes its result instead.
