08 · map() vs for LOOP
declarative · 1 line
const doubled = numbers.map(num => num * 2);
✓ concise, clear for array → array
imperative · 4 lines
let doubled = [];for (let i = 0; i < numbers.length; i++) { doubled.push(numbers[i] * 2);}
✓ more control: skip or break out
